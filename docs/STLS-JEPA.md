# STLS-JEPA：Surprise-Thresholded Latent Straightening JEPA

> 从 DTA-JEPA 进阶。**每一个改动都由 DTA-JEPA 实测出的诊断推出**，不是换名字重包装。
> 四条诊断 → 四处改动，一一对应；没被测出问题的部分一律不动（YAGNI）。

## 0. 起点：DTA-JEPA 测出来的四个病

| # | 实测诊断（证据位置） | 说明 |
|---|---|---|
| D1 | **规划器受限**：H=8、10 步 GD、6 重规划时三种方法成功率被压在同一水平 | 潜空间的**代价地形**不好，GD 找不到好的动作序列；AdaJEPA 的底座世界模型本来带 temporal straightening，我们这一版漏了 |
| D2 | **方差头排序有效、尺度失真**：Spearman 0.55–0.64，相对校准误差 82%；复查后**全局尺度其实成立**（mean err 25.8 vs mean var 22.8 ⇒ 比值 1.13），被压缩的是**条件区间**（分位预测 2.7–6.8 对应真实误差 11.7–52.0） | 控制器信号是**原始 MSE + 滞后 EMA**（`err/EMA(err)`），episode 早期 EMA 追不上 ⇒ 比值≈1.4、分配**饱和在 4× 学习率、2.2 步**上界，"只在需要时多花算力"没实现 |
| D3 | **锚点球每步都绑定**：ε_f=0.8、594.7k 快参数、η=5e-4 时，一步 Adam 的范数 ≈ η√n = 0.77 ≈ ε ⇒ 每 episode 159 次投影 | 有效步长由**信赖域**而非学习率决定；`w/o safety` 消融反而最好，印证安全层在吃掉适应能力 |
| D4 | **递归是条件性的**：深度 1→3 回收 42% 误差、第 4 步变差；但在**动力学偏移**下递归让误差单调变大（97.3→130.5） | 递归只在"算子可信"时是增益；偏移类型决定该花**迭代**还是花**适应** |

## 1. 名称与形式定义

**STLS = Surprise-Thresholded Latent Straightening**（惊讶阈值化 · 潜轨迹直化）

四种资源仍然只有一种信号（惊讶）驱动，但这条信号先被**标定**，再以**分位数阈值**分级触发；
同时潜空间的**几何**被显式优化为"直"，并把递归深度交给"惊讶 × 曲率"双门控。

### 1.1 L — 潜轨迹直化（修 D1）

预训练新增二阶差分（曲率）项：

\[
\mathcal L_{\text{str}}=\mathbb E\Big[\tfrac1{d}\big\|z_{t+1}-2z_t+z_{t-1}\big\|_2^2\Big]
\quad+\quad \tfrac1d\big\|\hat y_{t+1}-2z_t+z_{t-1}\big\|_2^2
\]

第一项约束**编码器**给出的窗口本身接近直线（梯度入编码器），第二项约束**预测器**把这条直线
延续下一步（梯度入 R 模块）。总损失：`L = L_pred + L_multi + 0.1·L_unc + 1.0·L_reg + 0.1·L_inv + λ_str·L_str`，
`λ_str = 0.1`。

为什么能修 D1：GD 规划在潜空间最小化 `Σ‖ŷ_k − z_g‖²`。轨迹越接近直线，代价对动作序列越接近
凸/二次型，Adam 的 10 步就越可能找到好解；这是 AdaJEPA 底层 temporal straightening
（Wang et al., ICML 2026）的原始动机，我们此前只用 SIGReg 约束了**分布**，没有约束**轨迹形状**。

### 1.2 T — 惊讶的阈值化分配（修 D2）

两步：

**(a) 温度标定。** 在**闭环 probe 基线**（同架构、lr=0、只记录不更新）的留出轨迹上拟合标量 τ，使标定后惊讶均值为 1：

\[
\tau=\mathbb E\big[e^\top\Sigma^{-1}e\big],\qquad s_{\text{cal}} = \frac{e^\top\Sigma^{-1}e}{\tau}
\]

（这就是 `Σ_cal = τΣ` 的极大似然温度，闭式解，一次前向即可拟合。）

**(b) 分位数分级。** 用分布内 `s_cal` 的 **75% / 95%** 分位数作阈值（75 分位＝"明显高于常态才多花一步"，避免分布内
平均分配数又回到 2）：

\[
U_t = 1+\mathbb 1[s_{\text{cal}}>q_{75}]+\mathbb 1[s_{\text{cal}}>q_{95}],\qquad
\eta_t=\eta_{\min}+(\eta_{\max}-\eta_{\min})\frac{U_t-U_{\min}}{U_{\max}-U_{\min}}
\]

为什么能修 D2：阈值有**外部参照物**（分布内分位数），不再依赖滞后 EMA；闭环参照实测 τ=1.54 / q₇₅=1.15 / q₉₅=2.64（push 族，126 次更新），分布内平均 U≈1.3。
两点实现细节比"选哪个分位"更要命，已记录在案：喂给控制器的惊讶必须用**预测方差**归一化
（早期版本喂的是原始 MSE，另一处喂的是 MC **认知**方差，两者都不是温度拟合时用的量），
且这个方差必须真的送达控制器（调用点曾硬编码 `unc=0.0`）。修好后闭环 τ=1.54 vs 开环 1.09——差别不大，
真正的缺陷是**量纲/量本身**，不是流。温度本身**几乎是空操作**，因为非直化模型的全局比值本来就是 1.13–1.19。这反而把问题定位得更准：要修的不是**尺度**，而是**参照物**（滞后 EMA → 外部固定分位）。温度保留为诊断用的量（τ≫1 才说明尺度真的坏了），阈值才是起作用的那一半；
标定后"惊讶=1"有明确含义，可以跨流比较（也回应了附录 B 里"跨流惊讶不可比"的问题）。

### 1.3 S — 稳定层：锚点半径按步数预算标定（修 D3）

\[
\epsilon_f = c\,\eta_f\sqrt{n_f}\,\bar U\,\bar R
\]

`n_f`=快参数个数、`ŪR̄`=每 episode 预期更新步数（默认 2×6=12），`c=0.5`。594.7k 参数、η=5e-4、
U=2.2、R=10 → ε≈8。语义变成"**整段 episode 的累计漂移上限**"，而不是"一步的位移"，
于是学习率重新掌握步长、锚点只在真正跑偏时兜底。同时保留逐步梯度裁剪与验证门控回滚。

### 1.4 S — 选择性递归深度（修 D4）

\[
K_t=\begin{cases} 1 & \text{曲率} \le \text{median}\ \text{（轨迹已直）}\\ \min(3,\ 1+\mathbb 1[s_{\text{cal}}>q_{60}]+\mathbb 1[s_{\text{cal}}>q_{90}]) & \text{否则}\end{cases}
\]

上限压到 **3**（实测第 4 步有害），且当轨迹已经直时**不迭代**。这一条同时承认 D4 的反例：
动力学偏移下算子本身是错的，多迭代放大错误——那种情形下该由 §1.2 的"多适应"来应对，
而不是由 §1.4 的"多迭代"。

## 2. DTA-JEPA → STLS-JEPA 差异

| 维度 | DTA-JEPA | STLS-JEPA |
|---|---|---|
| 预训练目标 | 预测 + SIGReg + 方差下限 + 逆动力学 + 深度监督 | **+ 潜轨迹直化（曲率）** |
| 分配策略 | 比值 sigmoid（`s_t/EMA(s_t)`）连续映射 | **温度标定 + 60/90 分位阈值分级** |
| 递归深度 | 由惊讶连续映射到 1..4 | **曲率门控 + 惊讶分级，上限 3** |
| 锚点半径 | 手设 0.8（≈一步 Adam） | **c·η√n·U·R（整段预算）** |
| 显式诊断依赖 | — | 每项都对应一条实测诊断 D1–D4 |

## 3. 评估与预期（可证伪）

同一底座模型、同规划器、同 episode 集，四方法对比：`frozen / AdaJEPA / DTA-JEPA / STLS-JEPA`。

| 指标 | 预期 | 若不符则说明 |
|---|---|---|
| shape 族成功率 | STLS ≥ DTA（直化改善 GD 条件数） | 直化项无效或权重不当 |
| dyn 族（可达 ×5 档） | STLS 保持 DTA 的领先（适应仍由阈值触发） | 阈值化分配丢了动力学偏移的增益 |
| 每 episode 锚点投影次数 | 从 ~159 降到 O(10) | ε 标定未生效 |
| 每 episode 平均更新步数 | 从 2.2 降到 1.2–1.5（分布内多数为 1） | 阈值仍偏高，分配继续饱和 |
| 规划成功曲线上升斜率 | 30 步曲线在 STLS 下更陡 | 直化没改善代价地形 |

**失败也要报**：若 STLS 不优于 DTA，结论就是"D1–D4 的诊断成立，但对应的四项修补并未转化为成功率"，
这仍然是可发表的负结果，且比改名换包装更有信息量。
